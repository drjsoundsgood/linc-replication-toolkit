# Module catalog

Training in LiNC is delivered as **modules**: short, self-contained units, each covering one technique or concept. Each module is taught by a **mentor pair**: one mentor explains the concept at the whiteboard, the other leads the bench work using **show, do, watch**. See [The mentorship cascade](../docs/09-mentorship-cascade.md).

## Example: the founding lab's module set

The founding lab studies RNA structure and RNA–protein interactions. Its modules are grouped into arcs that walk students through the whole story: **make an RNA, make a protein, study their structures, and study how they interact.**

| Arc | # | Module |
|---|---|---|
| **Make an RNA** | 1 | RNA transcription |
| | 2 | RNA purification: HPLC |
| | 3 | RNA purification: desalting and precipitation |
| **Make a protein** | 4 | Protein part 1: transformation |
| | 5 | Protein part 2: expression |
| | 6 | Protein part 3: harvesting |
| | 7 | SDS-PAGE gels |
| | 8 | Cleavage assays |
| | 9 | Immobilized metal affinity chromatography (IMAC) |
| | 10 | Protein part 4: size-exclusion chromatography (SEC) |
| **Study how they interact** | 11 | Binding assays: electrophoretic mobility shift assay (EMSA) |
| | 12 | Binding assays: filter dot blot |
| **Study structure: NMR** | 13 | NMR: basics of experimental setup |
| | 14 | NMR: basics of studying biomolecules |

| **Study structure: computation** | 18 | MD simulations: theory |
| | 19 | MD simulations: basic simulation setup |

Not every student takes every module. Students take the modules their project needs, and returning students take more advanced modules in later summers.

## Building your own set

1. **List the techniques your lab uses** that are safe and teachable to high school students. Check with your safety office.
2. **Group them into arcs** that tell a scientific story from start to finish (for example, make it → purify it → measure it → interpret it).
3. **Size each module** to one session, typically a half day or less.
4. **Assign a mentor pair to each module.** Spread modules across the lab so no one carries too many.
5. **Mix in theory and computational modules.** They show that research isn't only bench work, and they're a good way to involve lab members whose work is computational.
6. **Map modules to projects.** For each student project, list which modules it requires.
